Introduction to Equilibrium

Equilibrium is a game played only by reversible reactions.

At equilibrium, concentrations remain constant, but the system is dynamic: (forward and reverse reactions continuously occur at the exact same rate, as shown below.)

A ⇌ B + C

How it seems

Macroscopic view: Concentrations appear constant.

What actually happens

Microscopic level: Dynamic equilibrium.

Rate(Forward) = Rate(Backward)
